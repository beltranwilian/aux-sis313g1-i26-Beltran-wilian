Preguntas Teóricas

1. Formas de conectar HTML con JavaScript

La primera forma es interna, utilizando la etiqueta script directamente en el archivo HTML donde se escribe el código. Ejemplo:

    <script>
        alert("Hola Mundo");
    </script>

La segunda forma es externa, vinculando un archivo independiente con extensión .js mediante el atributo src de la etiqueta script. Ejemplo:

    <script src="script.js"></script>

2. Paso a paso para visualizar resultados en la consola

  1. Abrir el archivo HTML en cualquier navegador web.
  2. Hacer clic derecho en cualquier parte de la página y seleccionar Inspeccionar, o presionar la tecla F12.
  3. Hacer clic en la pestaña que dice Consola o Console en la ventana de herramientas de desarrollador.
  4. Observar los resultados o mensajes generados por las instrucciones del código JavaScript.

3. Variables en JavaScript (var, let y const)

Las variables son contenedores para almacenar datos. 'var' tiene un alcance de función o global y permite la redeclaración. 'let' tiene un alcance de bloque y no permite redeclarar en el mismo ámbito. 'const' tiene alcance de bloque y define valores constantes que no pueden ser reasignados.

    var nombre = "leonardo";
    let edad = 30;
    const pi = 3.1416;

Actualmente ya no se recomienda utilizar 'var' porque su alcance global o de función suele causar errores lógicos al permitir duplicar nombres de variables sin advertencia, además de sufrir de elevación (hoisting) de manera impredecible.
