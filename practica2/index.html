CUESTIONARIO GIT

  1. ¿Qué es una rama? Una línea de tiempo independiente para el código.
  2. ¿Cómo se crea/cambia? Con git branch y git checkout.
  3. ¿Diferencia main vs otras? Main es la versión oficial; las otras son de trabajo.
  4. ¿Cómo se combinan? Con el comando git merge.
  5. ¿Qué es un conflicto? Cambios incompatibles que se resuelven a mano.
